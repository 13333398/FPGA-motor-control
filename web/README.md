# 上位机监控（网页版）

## 为什么不需要额外通信模块

Tang Nano 20K 板上那颗 BL616 已经提供了 **USB 转串口**：

```
FPGA 69 脚(TX) ──► BL616 ──► USB Type-C ──► 电脑 COMx
```

所以电脑这一端只要读这个串口就行。**HDMI 只能输出图像，不能传数据**，
SD 卡只能离线记录，所以 USB 串口是唯一的数据通道。

网页通过浏览器的 **Web Serial API** 直接打开 COM 口，
不需要装驱动、不需要服务器程序、不需要联网。

## 怎么用

1. 双击 `start.ps1`（或右键 → 使用 PowerShell 运行）
2. 浏览器自动打开 `http://localhost:8000/dashboard.html`
3. 点 **连接串口** → 在弹窗里选板子的 COM 口
4. 板子每 500 ms 发一帧，界面开始刷新

> 必须用 **Edge 或 Chrome 桌面版**，Firefox / Safari / 手机浏览器不支持 Web Serial。
> 如果双击没反应，打开 PowerShell 执行：
>
> ```powershell
> cd "C:\Users\26349\Documents\Codex\2026-10-14\new-chat\outputs\motor_pid\web"
> python -m http.server 8000
> ```
>
> 然后手动打开 `http://localhost:8000/dashboard.html`。

## 界面能看什么

| 区域 | 内容 |
| --- | --- |
| 六个卡片 | 目标转速、实测转速、误差、占空比、帧率、累计丢帧 |
| 主曲线 | 目标线（橙色虚线）+ 实测线（蓝色实线），最近 600 点约 5 分钟 |
| 导出 CSV | 时间、目标、实测、占空比、帧号，可直接用 WPS/Excel 画图 |
| 演示数据 | 没有硬件时生成模拟数据，验证界面 |

## 界面能控制什么

连上串口后，控制栏可以：

| 按钮 | 发送的命令 | 效果 |
| --- | --- | --- |
| 设置转速 | `T<n>\n` | 目标转速设为 n RPM（0~600） |
| 停止 | `T0\n` | 停机（斜坡降到 0） |
| 反转 | `R\n` | 切换正反转（先减速再换向） |
| 清除报警 | `C\n` | 清除堵转报警 |

FPGA 侧对应 `src/uart_rx.v`（70 脚接收）+ `src/cmd_parser.v`（命令解析）。

## 常见问题

| 现象 | 原因 |
| --- | --- |
| 按钮点了没弹窗 | 浏览器不支持 Web Serial，换 Edge/Chrome |
| 弹窗里没有 COM 口 | USB 线没插好 / 板子没上电 |
| 连接后没有数据 | 串口被 PowerShell 监视器等程序占用，先关掉 |
| 数值乱跳 | 波特率不是 115200（代码里已固定） |

## 数据格式

板子每 500 ms 发一帧 ASCII：

```
S0077 T0078 D019B N012A
```

- `S` 实测转速（16 进制）
- `T` 目标转速（斜坡值，能看到软启动）
- `D` 占空比 0~3FF
- `N` 帧序号（用来统计丢帧）
